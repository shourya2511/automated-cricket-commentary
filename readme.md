Watches cricket match video and automatically generates
natural language commentary — like a real commentator —
using object detection, pose estimation, shot classification,
and a large language model.

- YOLOv8 — player & ball detection
- MediaPipe Pose — skeleton keypoint extraction
- PyTorch LSTM — shot type classification
- Gemini API — commentary text generation
- Streamlit — live demo dashboard
